Practices

Every week has a practice in the course database. Each lab README lists every command with the output you should see, and ends with a report template. Submit the report with the numbers you measured in your own container. Find each one on its week page from the schedule.

Peer review

The careers, big data and relational-problem assignments are peer-reviewed. You review three classmates’ reports against the published rubric, and the instructor moderates the marks. A review with scores but no reasons costs the reviewer marks.
