Resources

Running the labs

Every lab runs in the course containers; see Setup. Each command is a single docker exec … line or a Python command on your laptop, so it works the same on Windows, macOS and Linux. Generated data uses fixed seeds: everyone gets the same counts and totals, so use them to check your report.

References you will use every week

  • PostgreSQL 16 documentation
  • pgvector
  • MongoDB manual
  • Apache Cassandra documentation
  • DuckDB documentation
  • Chroma documentation
  • Docker documentation

Getting help

Ask in class, in the course channel, or in office hours. If a lab command fails, bring the command, the full error message and the output of docker compose ps.

Fixing this site

This site is a public repository. Found a broken link, a wrong date or a typo? Open an issue or send a pull request. Corrections are welcome and credited.
