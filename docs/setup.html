Setup

Do this before the Week 1 class. It takes about 20 minutes, mostly waiting for the first image download. You do not install PostgreSQL itself: everything runs in a container.

What you need

  • Docker: Docker Desktop on Windows or macOS, or Docker Engine with the Compose plugin on Linux.
  • About 2 GB of free disk for Weeks 1–8. Week 9 adds MongoDB and Cassandra (about 1.5 GB more, and at least 4 GB of RAM for Docker). Weeks 10–12 add Python AI packages (about 2 GB).
  • Python 3.10 or later from Week 3 on.

Get the course kit

The kit holds the Docker setup, every lab, the assignments and the project template. Labs are added as the weeks are released, so download it again, or git pull, each week.

Download the kit (zip)Browse it on GitHub

Or clone the repository:

git clone https://github.com/afnhsn-ibu/ce502-db.git
cd ce502-db/kit

Start the database

In a terminal (PowerShell on Windows) opened in the kit folder, the one that contains docker-compose.yml:

docker compose up -d --build
docker compose ps

Wait until ce502-postgres shows healthy, then run the setup check described in the full guide.
