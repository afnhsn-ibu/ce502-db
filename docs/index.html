Advanced Topics in Database Systems

Twelve weeks that follow one path: how a single database survives crashes and concurrent users, how one database becomes many, what changes for analytics and scale, and how databases search by meaning in the AI era.

one database→many databases→analytics and scale→AI-era databases

One session of about three hours each week: three 45-minute lessons and a practice.  ·  International Balkan University, Skopje  ·  [Semester]

Before the first class

Install Docker and start the course database by following the setup guide. It takes about 20 minutes, most of it waiting for the first download, and Practice 1 starts from a running container. Then read the syllabus.

Key point: every week answers one question: what does the database have to do so that the data is still correct, still there and still fast when something goes wrong or grows?
